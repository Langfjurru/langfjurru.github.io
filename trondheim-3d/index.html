Ruteplan uavhengig av GPS · v2.58.2

Trondheim 3D – Rettede favoritter

Dette verktøyet henter den faktiske v2.58.1-filen fra GitHub, legger til planlagt bussrutetrasé og dagens avganger uten GPS-avhengighet, og lagrer en komplett index.html som du kan laste direkte opp på GitHub.

Ruten kan dermed åpnes som favoritt selv om bussen ikke er ute og kjører. Holdeplasser, hurtigbåter, ferger, tog og kartmotor beholdes.

Hvis nettleseren blokkerer GitHub-hentingen: Last ned gjeldende trondheim-3d/index.html fra GitHub og velg filen nedenfor.

Klar. Ingen filer endres før du selv laster opp den nye index.html på GitHub.

Etter nedlasting: Erstatt bare trondheim-3d/index.html på GitHub, publiser endringen, og test bussfavoritt på en linje uten aktiv GPS-posisjon. De gamle favorittene blir værende i nettleseren.
