Om kartet og datakildene

Bakgrunnskart: OpenFreeMap / OpenStreetMap. 3D-terreng: Mapterhorn. Bygninger: OSM-høyder (ikke Kartverkets NHM-modell). Busser: Entur. Skip og Vegvesen: Allemannsdata. AIS oppdateres omtrent hvert minutt, men den underliggende posisjonen kan være eldre. Vegvesen leverer siste tilgjengelige hele timer, ikke løpende GPS. Ingen posisjoner er simulert.

3D: høyreklikk + dra på PC eller bruk to fingre på mobilen. Klikk på busser, fartøy, tellepunkter eller bygninger for detaljer. Anbefalt: publiser filen på en vanlig HTTPS-side som GitHub Pages. En lokal Android content://-adresse kan hindre kartfliser og API-kall. Dersom kartet er tomt, bruk knappen for 2D-reservekart.
