Om kartet og datakildene

Bakgrunnskart: OpenFreeMap / OpenStreetMap. 3D-terreng: Mapterhorn. Bygninger: OSM-høyder (ikke Kartverkets NHM-modell). Busser: Entur. Skip og Vegvesen: Allemannsdata. AIS-posisjoner hentes bare når fartøylag er aktivert, og oppdateres omtrent hvert femte minutt, som passer med mellomlagringen hos Allemannsdata. AIS-fartøy beveges ikke kunstig mellom gamle posisjoner. Vegvesen leverer siste tilgjengelige hele timer, ikke løpende GPS. Holdeplasser vises med store trykkbare bussikoner fra Entur Geocoder v3 og avgangstavler via Journey Planner v3, med oppdatering omtrent hvert 30. sekund mens tavlen er åpen. Bussene animeres mellom mottatte GPS-posisjoner. I v2.4 er vegtilpasning og detaljerte 3D-busser alltid aktivert. GPS-animasjonen videreføres fra v1.5. Detaljerte busser tegnes med Three.js ved nær zoom og som mindre, formriktige bussymboler ved oversiktszoom. Størrelsesovergangen er glidende og påvirker ikke GPS-funksjonen. AIS via Allemannsdata sin find_vessels_nearby har normalt 300 sekunders mellomlagring og viser kun sist rapporterte posisjon. Åpne AIS-data omfatter ikke alle fiskefartøy og fritidsbåter. Dette er anslått vegvalg mellom GPS-fikser, ikke en kontrollert planlagt AtB-avgang eller garantert korrekt linjetrasé. Uten sikker match brukes den tidligere jevne animasjonen. I v2.4 bruker rutekartet den konkrete avgangens ServiceJourney-ID i Entur Journey Planner; vegen i sanntidsanimasjonen er framleis vegtilpassa som i v1.5.

3D: høyreklikk + dra på PC eller bruk to fingre på mobilen. Trykk på ein buss eller rutenummeret for å vise planlagd trase frå start til slutt. Klikk på fartøy, tellepunkter eller bygninger for detaljer. Anbefalt: publiser filen på en vanlig HTTPS-side som GitHub Pages. En lokal Android content://-adresse kan hindre kartfliser og API-kall. Dersom kartet er tomt, bruk knappen for 2D-reservekart.

    Planlegg dagen

    Sjekk temperaturen og nedbøren før du går til bussen. Værkartet er separat fra sanntidskartet.

    🌧️ Nedbørskart fra Yr

    Den tidligere lenken gav 404. Vi viser ikke lenger en ugyldig Yr-modul. For å bygge inn nedbørskartet trenger vi koden som Yr selv genererer.

    Se nedbør på Yr ↗ Velg «Kart» og deretter «Nedbør» på Yr. I modulbyggeren velger du Trondheim og «Vis kode».

    Yr oppdaterer værkartene automatisk. Bruk tidslinjen inne i kartet. Dersom Yr begrenser innbyggingen i nettleseren din, åpne kartet direkte.
